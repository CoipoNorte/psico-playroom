# [🏠 Refugio](https://coiponorte.github.io/psico-playroom/)

**Una casa tranquila para tomarte un momento.**

Refugio es una casa virtual con diez habitaciones. En cada una hay objetos que puedes tocar
y usar de verdad: un telescopio que muestra el cielo, un oso que se deja abrazar, un xilófono
que suena, un tangram para armar, una planta que crece con los días.

No hay que registrarse, no hay que pagar, no hay prisa. Entras, te quedas lo que quieras
y sales cuando quieras.

ENLACE: https://coiponorte.github.io/psico-playroom/

---

## ¿Para quién es?

Para cualquier persona que busque un rato de calma, de juego o de descanso. Cada habitación
indica la edad recomendada; algunas son para todas las edades y otras van mejor a partir
de cierta edad. Si la usa un niño o una niña, se recomienda la compañía de una persona adulta.

## Las habitaciones

| | Habitación | Qué hay dentro |
|---|---|---|
| 🏠 | **El Vestíbulo** | Un perchero para colgar lo que pesa, un reloj, un paraguas para escuchar la lluvia |
| 🧸 | **Rincón de Peluches** | Un oso y un conejo que se acarician, se abrazan y te escuchan; una manta; un espejo |
| 🎵 | **Sala de Instrumentos** | Xilófono, tambor con metrónomo, flauta, campana, pandereta |
| 🍲 | **Cocina del Cuidado** | Una olla para remover, infusiones con su tiempo, recetas sencillas, un frutero |
| 🎨 | **Taller de Creatividad** | Lienzo con pincel, crayón y plastilina; papel para arrugar o lanzar; un tangram |
| 📚 | **Biblioteca Serena** | Cinco cuentos cortos con marcapáginas, una butaca, una lámpara |
| 🌬️ | **Sala de Respiración** | Burbujas que soplas, una vela, un globo, un reloj de arena |
| 🌱 | **Jardín Interno** | Una planta que crece de verdad con el tiempo; una mariposa que se posa si te quedas quieto |
| 🤸 | **Sala de Movimiento** | Una pelota para lanzar, estiramientos guiados, una cinta que sigue tu mano |
| 🌙 | **Mirador de Estrellas** | Telescopio, constelaciones, la fase de la luna de hoy, un planetario y una maqueta 3D con las lunas |

Cada habitación tiene además una **actividad guiada opcional** de pocos pasos. Puedes
seguirla, saltarte partes o ignorarla por completo.

La maqueta 3D (**opción B** del planetario) necesita un navegador con WebGL2. Si no está disponible, el
**mapa orbital (opción A)** sigue mostrando las mismas posiciones reales.

## Cómo se usa

1. **Lee el instructivo** de la entrada y pulsa *«Entrar a la casa»*.
2. **Recorre la casa completa.** Verás las diez habitaciones ilustradas por dentro en corte,
   el jardín, el cielo (día, tarde o noche) y un pequeño visitante que camina contigo usando el
   ratón, las flechas del teclado o los controles de recorrido. Toca cualquier habitación para
   entrar, o cambia a *Lista* para buscar por nombre o tema.
3. **Toca los objetos.** Cada uno se abre para usarlo. También puedes arrastrarlos
   para cambiarlos de sitio. La ventana y la decoración de cada habitación responden
   al tacto: puedes cambiar su luz o su ambiente y la casa lo recordará.
4. **Sigue una actividad, si te apetece.** Cada etapa señala un objeto de la escena
   que puedes abrir directamente. También puedes saltar etapas o ir hacia atrás.
5. **Escribe en el diario** si quieres. Es privado y solo tú puedes verlo.
6. **Ajusta la casa** a tu gusto: sonido, animaciones, tu nombre y tu color.

Funciona con el ratón, con el dedo en el móvil y con el teclado.

## Tu privacidad

- Refugio **no pide cuenta ni contraseña** y no recoge datos personales.
- Todo lo que guardas (diario, progreso, la planta del jardín) se queda **en tu navegador**.
  No se envía a ningún servidor.
- Desde *Ajustes* puedes borrar todo cuando quieras.
- El sonido viene apagado. Se activa con el interruptor de arriba.

## Un aviso importante

> Refugio es un espacio de acompañamiento voluntario. **No es un servicio de emergencias,
> atención clínica ni diagnóstico.** Si necesitas ayuda profesional, busca un servicio de
> salud mental de tu localidad. Puedes pasar, detenerte o no compartir en cualquier momento.

## Para publicar tu propia copia

Si quieres tener Refugio en tu propia página de GitHub:

1. Descarga este proyecto.
2. Abre `deploy.bat`, escribe tu usuario de GitHub en `GH_USER` y el nombre del repositorio en `GH_REPO`.
3. Haz doble clic en `deploy.bat`.

El script sube el código y publica la página. La primera vez tarda uno o dos minutos en
aparecer. Los detalles técnicos están comentados dentro del propio `deploy.bat`.
